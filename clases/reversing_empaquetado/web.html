01 · La medida que decide todo

¿Está cifrado, o solo codificado?

La primera pregunta no es «¿cómo lo descifro?». Es esta. Y no se responde mirando: se mide.

La entropía cuenta cuánta sorpresa hay por byte. Si un fichero usa pocos símbolos y los repite, es baja. Si los 256 valores salen por igual, es máxima: 8 bits por byte.

0 2 4 6
4,5código fuente, texto 6,0base64 8,0cifrado o comprimido 
import math, collections

def entropia(b):
    if not b: return 0.0
    c = collections.Counter(b)
    n = len(b)
    return -sum((k/n) * math.log2(k/n) for k in c.values())

El bloque de la muestra dio 6,00. Eso es base64, no cifrado: el base64 solo usa 64 símbolos de los 256 posibles, y esa limitación se ve en el número. Lo descodifiqué y lo que salió debajo dio 8,00.

Ese 8,00 cierra una puerta y abre otra.

Cierra: no hay codificación que deshacer. Es cifrado de verdad y sin la clave no sale.

Abre: si está cifrado, la clave tiene que estar ahí dentro, porque el programa se descifra a sí mismo cada vez que lo ejecutás.

02 · La idea

Te lo está entregando

Buscando en el fichero aparece la rutina que lo abre:

const clave  = crypto.pbkdf2Sync(pass, salt, 100000, 32, 'sha512');
const dec    = crypto.createDecipheriv('aes-256-cbc', clave, iv);
const codigo = dec.update(BLOQUE, 'base64', 'utf8') + dec.final('utf8');

new Function('exports','require','module','__filename','__dirname', codigo)(...);

El camino obvio es sacar pass, salt e iv de la tabla de cadenas ofuscada. Lo intenté primero: monté un ataque de texto conocido probando 1.300 claves contra 31 entradas. Falló. Mi hipótesis sobre cómo estaba codificada la tabla era falsa, y punto.

Y entonces mirás la última línea otra vez. new Function(..., codigo). El programa mete el texto en claro dentro de una función para ejecutarlo. Si yo cambio qué es Function, me lo entrega y no ejecuta nada.

const Original = Function;

function interceptor(...args) {
  const cuerpo = args[args.length - 1];        // el ultimo argumento es el codigo
  if (typeof cuerpo === 'string' && cuerpo.length > 500) {
    require('fs').writeFileSync('/tmp/capturado.js', cuerpo);
    console.log('>>> CAPTURADO: ' + cuerpo.length + ' bytes');
    process.exit(0);                            // y NO lo ejecuto
  }
  return Original.apply(this, args);
}
interceptor.prototype = Original.prototype;
globalThis.Function = interceptor;

La idea, en general

Un programa protegido tiene que desprotegerse para funcionar. Buscá el punto donde está obligado a hacerlo y esperalo ahí. No rompés su protección: dejás que la termine.

03 · Casi nunca hay una capa

Muñecas rusas

Capturé 2.394.244 bytes. Los abrí esperando el programa. Lo que encontré empezaba así:

  const key = crypto.pbkdf2Sync(masterkey, salt, 100000, 32, 'sha512');
  ...

Otro desempaquetador. Y mi process.exit(0) al primer acierto me había parado justo ahí: por poco concluyo que el envoltorio era el programa.

Lo que llega4.263.196 B

Ofuscado, con un bloque de entropía 8,0 dentro.

se abre con Function ↓
Capa 12.394.244 B

No es el programa: es otro desempaquetador. Mismo PBKDF2, mismo AES.

se abre con Function ↓
Capa 21.794.650 B

Ya no descifra nada. Esto es el programa. Y aquí se para, sin ejecutarlo.

La corrección es de una línea: en vez de parar al primer acierto, parás cuando el texto deja de ser un envoltorio.

function esDesempaquetador(t) {
  return t.includes('createDecipheriv') || t.includes('pbkdf2Sync');
}

if (!esDesempaquetador(cuerpo)) {
  analizar(cuerpo);       // ya no descifra nada mas: es el programa final
  process.exit(0);
}
// si SI lo es, se deja correr para que entregue la siguiente capa

04 · El gancho que no se puede esquivar

Function funciona, pero tiene una pega: solo lo pillás si el programa usa Function. Podría usar eval, o vm.runInThisContext, o ejecutar el resultado en línea sin pasar por ninguno.

Hay un sitio del que no puede escapar: para descifrarse, tiene que llamar al descifrador.

const crypto   = require('crypto');
const original = crypto.createDecipheriv;
let n = 0;

crypto.createDecipheriv = function (...a) {
  const dec = original.apply(crypto, a);
  const partes = [];
  const u = dec.update.bind(dec), f = dec.final.bind(dec);

  dec.update = function (...x) {
    const r = u(...x);
    partes.push(typeof r === 'string' ? r : r.toString('latin1'));
    return r;
  };
  dec.final = function (...x) {
    const r = f(...x);
    partes.push(typeof r === 'string' ? r : r.toString('latin1'));
    require('fs').writeFileSync('/tmp/claro' + (++n) + '.js', partes.join(''));
    return r;
  };
  return dec;
};

Con esto cae cada descifrado, vaya después a donde vaya. Es el gancho que pondrías primero si volvieras a empezar.

05 · Lo que falta es un espía

La capa 2 dependía de módulos que no estaban: fs-extra, axios, archiver, sqlite3. Reventaba con Cannot find module.

Podías instalarlos. O podías darte cuenta de que un módulo que falta es una oportunidad: lo sustituís por algo que apunte todo lo que le pidan.

const Module = require('module');

function espia(nombre) {
  const base = function () {};
  const p = new Proxy(base, {
    get(t, k) {
      if (k === 'then' || k === 'toJSON') return undefined;   // que no parezca promesa
      if (k === 'default') return p;
      return espia(nombre + '.' + String(k));
    },
    apply(t, th, a) {
      log('[LLAMADA] ' + nombre + '(' + a.map(resumir).join(', ') + ')');
      return espia(nombre + '()');
    },
    construct(t, a) {
      log('[NUEVO] new ' + nombre + '(' + a.map(resumir).join(', ') + ')');
      return espia('new ' + nombre);
    }
  });
  return p;
}

const cargaOriginal = Module._load;
Module._load = function (peticion, padre, esMain) {
  try { return cargaOriginal.apply(this, arguments); }
  catch (e) { return espia(peticion); }          // no existe -> espia
};

Y cuando el programa llama a axios.post(URL, datos), la URL queda escrita. No hizo falta descifrar nada: la descifró él solo para poder usarla.

El detalle del then: si un Proxy devuelve algo para la propiedad then, JavaScript lo trata como una promesa y un await se cuelga para siempre. Devolvé undefined.

07 · El laboratorio

El orden no es un detalle: es lo único que lo hace seguro

# 1. red ARRIBA, solo para instalar lo que haga falta

# 2. red ABAJO, y se COMPRUEBA
ip link set eth0 down
ip addr show eth0 | grep -c 'inet '          # tiene que dar 0
ping -c1 -W2 1.1.1.1 && echo RED=SI || echo RED=NO

# 3. AHORA se toca la muestra

La muestra nunca ve una interfaz levantada. Y se comprueba, no se supone.

Nada de carpetas compartidas

Las carpetas compartidas de VirtualBox necesitan Guest Additions, que es código corriendo dentro de la máquina con un canal directo al anfitrión. Justo lo que no querés. Un disco ext2 de 24 MB no tiene canal de vuelta: se enchufa, se lee, se desenchufa.

dd if=/dev/zero of=entrada.img bs=1M count=24
mkfs.ext2 -L ENTRADA entrada.img
# copiar dentro la muestra y el arnes, y despues:
VBoxManage convertfromraw entrada.img entrada.vdi --format VDI

Y sin abrir una sola ventana

VBoxManage startvm lab --type headless
VBoxManage controlvm lab keyboardputstring "ls -la"
VBoxManage controlvm lab keyboardputscancode 1c 9c    # 1c = Intro, 9c = soltarlo
VBoxManage controlvm lab screenshotpng pantalla.png

Teclado y ojos. Nada aparece en tu escritorio.

08 · Los dos errores

Van aquí porque los vas a cometer vos también.

El instrumento antes que el objetivo

Dos veces seguidas el «no funciona» era mío. Primero estuve mandando órdenes por la consola serie a ciegas, dando por hecho que llegaban; una captura de pantalla mostró el login: intacto, sin una sola tecla recibida. Después mount fallaba con Invalid argument sobre un disco perfectamente válido —blkid decía TYPE="ext2"— porque el kernel virt de Alpine no trae ese driver cargado. modprobe ext4 y entró.

Regla

Cuando algo no funciona, sospechá de tu medición antes que del objetivo. Y conseguite una forma de ver, no de suponer.

La carga útil anula console.log

Los ficheros se seguían escribiendo, pero la salida por pantalla se cortaba en seco a mitad y el proceso terminaba con código 0, como si todo hubiera ido bien. Si tu instrumentación habla por consola, te quedás ciego sin enterarte.

// capturá la referencia ANTES de cargar la muestra, y escribí a fichero
const fs = require('fs');
function log(t) {
  try { fs.appendFileSync('/mnt/ent/log.txt', t + '\n'); } catch (e) {}
}

09 · El final

No afirmes negativos

La pregunta que de verdad importaba a la víctima era ¿deja algo instalado?, porque de eso dependía si tenía que formatear el equipo.

El primer barrido no encontró schtasks ni claves Run. Eso no es una respuesta, porque las cadenas seguían cifradas: «no encontré la palabra» no es «no está».

Para poder afirmarlo hicieron falta dos vías que no comparten supuestos:

  • Estática. Extraje del binario la maquinaria de cadenas —la tabla, los dos descifradores base y 817 funciones envoltorio—, la ejecuté en un fichero aparte y obtuve 1.185 cadenas en claro. Ninguna contiene schtasks, CurrentVersion\Run, RunOnce, Startup, sc create, .lnk ni .vbs.
  • Dinámica. De los 36 comandos ejecutados, las únicas operaciones de registro son reg query. Lectura.

Con una sola vía no lo habría afirmado. Con las dos, sí. Y esa conclusión cambió el consejo: en vez de formatear, rotación dirigida de credenciales y cierre de sesión en todos los dispositivos.

Lo que te llevás de la clase

Que no encuentres algo dice tanto de tu búsqueda como del objetivo. Antes de decir «no está», preguntate si tu búsqueda podía haberlo encontrado.
